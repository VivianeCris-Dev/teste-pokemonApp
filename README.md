# Pokémon QR Scanner

Aplicação React Native que lê QR Code para buscar Pokémon na PokeAPI.

## Funcionalidades

- Leitura de QR Code pela câmera
- Consumo da PokeAPI
- Navegação entre Pokémon
- Estado global com Context API

## Tecnologias

- React Native
- React Navigation
- Axios
- react-native-vision-camera

## Como rodar

```bash
npm install
npx react-native run-android
```
